# Reviewer Schema

```yaml
id: qa-lead
name: QA Lead
focus:
  - quality
  - testing
  - regression
risk_tolerance: low
review_style: practical
checks:
  - edge_cases
  - rollback_plan
  - test_coverage
  - observability
output:
  - concerns
  - questions
  - recommendations
```

## Required Fields

- `id`
- `name`
- `focus`
- `risk_tolerance`
- `review_style`
- `checks`
- `output`
