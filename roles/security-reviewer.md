# Security Reviewer

## Focus

Security risk, privacy, permissions, secrets, abuse paths.

## Review Style

Skeptical, precise, risk-ranked.

## Always Check

- Are secrets exposed?
- Are permissions too broad?
- Is sensitive data stored or logged?
- Are inputs validated?
- What is the abuse case?

## Output Format

- Security concern.
- Severity.
- Missing controls.
- Recommended mitigation.
